Pi

  • 极简 · 可扩展
  • 默认 4 个工具read · bash · edit · write
  • 没有沙箱

今天我们用 Pi Coding Agent 这个案例，来直观地跟大家介绍什么是一个 Agent Harness。

大家电脑上装的 Pi 是极简 Harness 的代表，核心就看两个取舍。第一是工具极简：默认只开 read、bash、edit、write 4 个基础工具，因为有了读写改和 bash 就能调机器上的命令干活，其他能力留给你通过扩展或接 MCP 按需往上加。

第二是护栏极简：它故意不做每步弹窗确认，也不带内置沙箱，把自由度留给使用者——如果要跑不放心的任务，官方建议直接把整个 Pi 放进容器或沙箱环境里跑。

另外提一句，Pi 被 Earendil 收购后仓库已迁到屏幕上这个新地址，并且现在已经支持连接 MCP。

为什么选 Pi 呢？因为它是一个非常极简的 Agent Harness，非常适合用来理解 Agent 底层的运行逻辑。别看它简单，其实它在 OpenRouter 上的排名非常靠前：排第 6，前面是 Hermes、Claude Code、OpenClaw 这些头部产品。它很受大家喜欢，连 Databricks 做评测，都把它放进去了。

OpenRouter 是一个大模型接口的中转平台，这个榜按经过它的 token 用量排。截图是我当时那个月的榜，每个月会变。

比如美国公司 Databricks，就拿自家几百万行代码的真实仓库做了基准测试。他们的测试挺有意思：第一，准备了很多自家的真实任务；第二，挑了多个知名的 Agent Harness，包括 Pi、Claude Code 等，和不同的大模型组合，对比执行这些任务的花费和效果，看什么样的 Harness 配什么模型表现最好。题目全部来自真实合并过的代码，不是玩具题。

我们看一下结果：竖轴是任务通过率，横轴是每个任务的花费。红线连着的是性价比最好的几组：花同样的钱，没有谁的通过率比它们高。线上的点大多是 Pi。

可以看到，当时用 Opus 4.8 配上 Pi，表现竟然比 Claude Code 配 Opus 4.8 还要厉害：思考强度都开到 xhigh 这一档时，通过率还略高一点，花费少了三成左右。思考强度就是让模型想多久。具体数字：Pi 大约 90%，每个任务 2.2 美元左右；Claude Code 大约 88%，3.2 美元左右。

接下来，我就通过它的 UI 界面，来给大家具体介绍一下 Pi Coding Agent。

这是 Pi 的图形界面，叫 pi-web，是社区做的，和命令行版用的是同一套配置和会话。大家看我标出来的这几块，基本就是一个 Harness 的零件：System，是它的系统提示词；左边这一列 Session，是一次一次的会话记录；Models，是背后接的大语言模型；Skills 是技能，Plugins 是扩展；Compact，是上下文压缩。输入框下面这个 default，是工具档位。所以我们下一节就从工具讲起，再讲记忆，然后用 Loop 把它们串起来，最后讲 Skills。
