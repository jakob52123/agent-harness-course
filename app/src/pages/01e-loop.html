接下来终于来到 Agent Loop 了。Agent Loop 就是把我们刚刚所提到的全部串起来：用户输入 User Prompt，Harness 再带上自己的 System Prompt，我们的 Harness 开始组织并装载上下文，然后丢给大语言模型进行判断。

模型判断之后，如果可以达成交付，就直接把结果返回给用户；如果还需要进一步行动，就会通过 Function Calling 的方式发起工具请求。

先过权限审查，通过后，Harness 执行工具，返回的结果再更新到上下文中，接着丢给模型，模型再去做判断。就这样一圈一圈转，直到可以交付。

Skills 就是把做事的 SOP 打包，主要包含这四块内容。

第一，SKILL.md，主要描述做事的 SOP。第二，脚本，做这件事要用的一些脚本，这样模型在处理时就不用重新写了。第三，Reference 参考资料。第四，输出模板。

这些都根据我们项目和流程的具体情况来定，可以提供，也可以不提供。

那 Agent 是怎么用上它的？平时只看技能的名字和一句话描述，不占地方；
