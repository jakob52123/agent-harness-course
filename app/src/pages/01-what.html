三句定义。先记学员版：Agent = 能自己动手的 AI。专业版：Harness 是包在模型外面的执行系统，负责运行工作循环，管理工具、上下文和记忆、权限、运行环境。通俗版：模型只会想和说，Harness 是让它能动手、记得住、不闯祸的一整套东西。

换司机这一步讲：同一个司机换辆车，干的事就不同；反过来，车不变，换个司机，还是这辆车的干法。模型是选的，Harness 是搭的。

Agent Harness的组成部分

02，Agent Harness 的组成部分。知道 Harness 是那辆车之后，这一章我们拆开车看里面有哪些核心零件、工作循环（Loop）又是怎么转起来的。

Harness 里有什么

LLM
工具
Context
Memory
Loop

接下来用一个浅显的比方跟大家解释什么是 Agent Harness，其实非常简单，就用开车来打比方。开车就是把你从 A 点送到 B 点，也就是在执行一个任务。

司机的判断，就是 LLM，大语言模型。

方向盘、油门、刹车，就是司机能调用的工具。他必须通过转动方向盘去执行任务，通过油门获得速度。

路况、仪表盘这些司机能看到的信息，就是上下文 Context。

我们走过的路线、行车记录，就是 Memory。

当然，除了这些非常显性的东西以外，还有一个比较隐性的：Loop。Loop 就是司机边看、边判断、边操作的过程。看，就是加载 Context；判断，就是 LLM 进行处理；操作，就是工具调用——大家看，车变道了；然后再看工具返回的结果。又要看、又要判断、又要操作，一圈一圈转下去。

整辆车，就是我们的 Agent Harness。只有司机没有车，没办法把你送到目的地；反过来，只有车没有司机，哪怕是自动驾驶，也得有个做判断的大脑，同样到不了目的地。OK，这就是一个 Agent Harness，包含 LLM、工具、Context、Memory 和 Loop。

LLM 提供判断，
Harness 组织执行

这页大家可以拍照留底。如果用开车来理解的话：LLM 是我们的司机；工具是方向盘、油门、刹车；Context 是路况、仪表盘；Memory 是行车记录；Skills 是驾驶手册，或者说有点像越野的路书；Agent Loop 是司机看、判断、再操作，观察到反馈之后，再看、再判断、再操作；安全边界就像交规和护栏一样，规范司机的行驶路径。这其实就是一个 Agent Harness。

一句话：LLM 提供判断，Harness 组织执行。

看想做 组装 Context 模型 Thinking Function calling

大模型自己不会动手，只会吐字；圈是外面的 Harness 程序带着模型在转。顺着屏幕上「看 → 想 → 做」三张卡看一圈怎么转：

第一步「看」，是组装 Context：由 Harness 把这一步要给模型看的信息组装成上下文（Context）喂给模型。第二步「想」，是模型 Thinking：模型拿到上下文开始思考（Thinking），决定下一步干什么。第三步「做」，是 Function calling：模型自己不调工具，只是通过 Function calling 吐出「我要调用哪个工具、参数是什么」；外面的 Harness 程序真正去执行工具，再把拿到的结果放回上下文（Context），接着转下一圈。

屏幕上这张五步图是帮大家看清一圈怎么走的教学拆解图：拼好这一步要给模型看的上下文（挡风玻璃）→ 模型想下一步（司机）→ 过权限（刹车）→ 调工具（方向盘）→ 结果放回上下文（挡风玻璃），没做完就接着转下一圈；如果产品配了长期记忆，任务结束后再把要留底的信息写进记忆（行车记录仪）。

真实产品落地时，不一定每一步都按这张教学图摆在圈里；哪些步骤会挪到圈外，我们到第 04 章拆解实际产品时再看。
